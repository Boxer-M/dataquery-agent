# 经营报告格式与验证参考

Modified by DataQuery Agent from Anthropic XLSX guidance under Apache-2.0. 本参考只描述后续报告实现需要验证的属性，不执行文件操作。

- 以明确的表头、字体和数字格式保持可读性，保留用户指定的字段和顺序；不擅自添加示例业务行。
- 标注数据来源、指标定义版本、时间窗口和业务限制，区分原始数据与派生展示。
- 原始 Decimal 字符串应可追溯。格式化不能恢复已经丢失的精度；单位和币种不明确时不推测。
- 上游将公式重算作为重要检查，但公式可计算不代表业务公式正确。未来任何公式必须来自审核过的模板并独立对账，不允许模型自由编写。
- openpyxl 写入公式不等于生成有效缓存；未来需分别检查公式、重算结果、缓存和业务真值。
- 原文提到的重算脚本，可能在公式报错时退出码仍为零；未来不能只凭退出码判断报告正确。本阶段不调用该脚本。
- 宏、外部链接、自动取数、复杂上传工作簿编辑与图形保真均不在 C1 范围。
