## 可直接使用的简历表述

- 构建基于 FastAPI、React、PostgreSQL 和 LangGraph 的本地经营分析工作台，将正式指标查询与经过审核的 PDF 检索纳入可追踪的 DAG，保留 SQL 来源和页码引用。使用 PostgreSQL Checkpoint 完成同一 Run 的跨重启人工澄清恢复。
- 为重复聚合查询引入按 Owner、Catalog 与数据版本隔离的 Redis 缓存，并在命中时复核数据库访问权限。本地三轮 360 请求对照中，并发 5 的 P95 从 140.34 ms 降至 118.08 ms，指标 SQL 调用由 2481 次降至 0。

面试可沿「自然语言 → 能力校验 → 指标和文档子任务 → 原始证据校验 → Query History」讲一个真实请求。需要展示故障时用 Catalog 定向恢复或 PDF 部分成功。先交代模型负责提案与委派，执行门负责权限及正确性，再打开对应运行记录。
